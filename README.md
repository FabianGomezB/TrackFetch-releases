# TrackFetch - descargas

Este repositorio **solo contiene los binarios publicados**. El codigo fuente no
vive aca.

La aplicacion consulta la ultima version publicada en:

    https://api.github.com/repos/FabianGomezB/TrackFetch-releases/releases/latest

## Que hay en cada release

- `TrackFetch-<version>-Setup.exe` - instalador para Windows (instala por
  usuario, no pide administrador y no toca tus datos).
- `TrackFetch-<version>.apk` - APK para Android; se instala encima de la version
  anterior siempre que este firmado con la misma clave.
